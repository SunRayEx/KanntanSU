# Merge Plan: me.weishu.kernelsu Backend → com.kanntan.su

## Goal
Delete me.weishu.kernelsu's UI code, keep its backend (Natives, KsuCli, data layer, repositories, ViewModels, utilities, KsuService). Wire com.kanntan.su's existing MD2 UI to use me.weishu.kernelsu's real data. Add all missing screens (ModuleRepo, Template, Flash, About, WebUI, ExecuteModuleAction) to com.kanntan.su.

## Constraints
- JNI functions in `jni.cc` are hardcoded to `Java_me_weishu_kernelsu_Natives_*` — me.weishu.kernelsu.Natives MUST stay as JNI entry point
- AndroidManifest namespace is `me.weishu.kernelsu` — app package stays as-is
- com.kanntan.su keeps its black/white MD2 aesthetic
- com.kanntan.su keeps its custom HomeScreen (geometric Canvas art)
- com.kanntan.su keeps its Screen enum navigation (not Navigation3)

## Architecture After Merge

```

├── Natives.kt               ← JNI bridge (must stay)
```
